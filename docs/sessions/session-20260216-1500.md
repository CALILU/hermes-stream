### Cambios Detallados

#### 1. DLNA Cast a TV
Envio de video a Smart TVs de la red local via protocolo DLNA/UPnP.

**Backend** (`lib/dlna.js` + `routes/dlna.js`):
- Descubrimiento SSDP de dispositivos MediaRenderer en la red (multicast 239.255.255.250)
- Control de reproduccion: play, pause, resume, stop, seek, volume
- Generacion de metadatos DIDL-Lite XML para los renderers
- Deteccion automatica de IP del servidor con `os.networkInterfaces()`
- 8 endpoints REST: `/api/dlna/devices`, `/scan`, `/play`, `/pause`, `/resume`, `/stop`, `/seek`, `/volume`, `/status`

**Frontend** (`useCast.js` + `CastButton.js` + `CastDeviceModal.js`):
- Hook `useCast` con polling de estado cada 2s cuando hay cast activo
- Boton Airplay con animacion pulsante
- Modal con lista de TVs, controles remotos (play/pause/stop), barra de progreso click-to-seek, slider de volumen

**Dependencias**: `node-ssdp@4.0.1`, `upnp-mediarenderer-client@1.4.0`

#### 2. Picture-in-Picture
Ventana flotante nativa del navegador para seguir viendo mientras se navega.

**Cambios en** `VideoPlayer.js`:
- Estado `isPiP` + funcion `togglePiP()` con `requestPictureInPicture()`
- Listeners `enterpictureinpicture` / `leavepictureinpicture`
- Boton PiP (icono `PictureInPicture2`) entre Cast y Fullscreen
- Tecla `P` como atajo
- Barra compacta fija en la parte inferior cuando PiP activo (titulo, progreso, volver, cerrar)
- Player principal se oculta (`invisible absolute`) pero se mantiene en DOM para que PiP funcione
- Panel de actores oculto durante PiP
- Check `document.pictureInPictureEnabled` para ocultar boton si no soportado

#### 3. Continuar Viendo
Seccion horizontal mostrando peliculas con reproduccion parcial.

**Hook** (`useVideoProgress.js`):
- Funcion `getAllVideoProgress()`: escanea localStorage, filtra expirados (>30 dias), retorna mapa filename→progress

**App.js**:
- `continueWatching` useMemo: filtra videos con progreso 5-95%, ordena por mas reciente, max 10
- Seccion JSX con scroll horizontal, posters, barra de progreso amarilla, porcentaje y tiempo
- Solo visible en vista principal (sin filtros/busqueda/coleccion activos)

#### 4. Aleatorio Inteligente (Sorprendeme)
Seleccion aleatoria ponderada con animacion de ruleta.

**Componente** (`RandomPickerModal.js`):
- Algoritmo de ponderacion: rating>=7 (+0.5), rating>=8 (+1.0), no visto (+1.0), no favorito (+0.3)
- Animacion: 20 ciclos de posters aleatorios, desacelerando progresivamente (100ms→400ms)
- Resultado: poster ampliado con titulo, rating, ano, duracion, sinopsis
- Botones "Reproducir" (lanza pelicula) y "Otra" (excluye anterior del pool)
- Funciona con filtros activos (ej: aleatorio solo dentro de Comedia)

**App.js**:
- Boton violeta "Sorprendeme" con icono Shuffle (desktop y movil)
- Estado `showRandomModal`
- Pasa `filteredVideos`, `favorites`, `allProgress` al modal

#### 5. Recomendaciones IA
Motor de scoring personalizado basado en perfil de consumo del usuario.

**Hook** (`useRecommendations.js`):
- Calcula perfil de afinidad por genero (de peliculas vistas >30% + favoritas)
- Recopila tmdbIds recomendados por TMDB desde peliculas consumidas
- Scoring por pelicula candidata:
  - Afinidad genero: 0-3 pts (suma de porcentajes * 3)
  - Recomendada TMDB: 0-2 pts (si aparece en recs de peli vista)
  - Rating TMDB: 0-1 pt (rating/10)
  - No vista: 0-1.5 pts
- Penalizacion de diversidad: -0.5 si genero ya domina el top
- Fallback: top rated si no hay historial
- Retorna top 15 con `_reason` personalizada

**Componente** (`RecommendationsSection.js`):
- Seccion horizontal con icono Sparkles morado
- Cada tarjeta: poster, badge rating, titulo, razon en morado ("Te gusta Accion", "Similar a Matrix")
- Clic para reproducir

### Decisiones Tecnicas
- **DLNA sin autenticacion**: Las TVs acceden a streams sin token porque IsiPrime ya auto-autentica IPs locales (192.168.x.x)
- **PiP mantiene DOM**: El player se oculta con `invisible absolute` en vez de desmontarse, porque `<video>` debe existir en DOM para que PiP funcione
- **Recomendaciones client-side**: No se necesita backend porque todos los datos (metadatos, favoritos, progreso) ya estan en el frontend
- **Aleatorio respeta filtros**: Usa `filteredVideos` en vez de `videos`, asi "Sorprendeme" dentro de un genero funciona

### Problemas Encontrados y Soluciones
- **Problema**: PowerShell rechaza `&&` para encadenar comandos
  **Solucion**: Usar `;` en su lugar: `cd F:\plex\my-ui; npm run build`

- **Problema**: El boton Cast no aparecia tras implementar
  **Solucion**: El frontend no estaba recompilado. Ejecutar `npm run build` en my-ui/

- **Problema**: PiP desmontaba el `<video>` al ocultar el player
  **Solucion**: Cambiar de ternario (que desmonta) a `invisible absolute` (que oculta sin desmontar)

- **Problema**: Variable `topGenreId` sin usar en useRecommendations.js
  **Solucion**: Eliminada la linea sobrante
