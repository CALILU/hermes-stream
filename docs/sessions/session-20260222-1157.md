# Sesion: 2026-02-22 11:57

## Objetivo de la Sesion
Implementar un modulo que muestre la capacidad total, espacio usado y libre del disco externo NAS conectado al router, visible en el modal de Configuracion (boton de herramientas) de IsiPrime.

## Trabajo Realizado

### Resumen
Se creo un sistema completo de consulta de espacio en disco que funciona tanto en modo local como FTP. Se probaron multiples estrategias para obtener datos del NAS Synology (comandos FTP nativos, API DSM, auto-descubrimiento por red, PASV IP) hasta llegar a la solucion definitiva: listado recursivo de archivos FTP + capacidad total configurable.

### Cambios Detallados

1. **Endpoint `GET /api/storage/disk-usage`**: Consulta espacio en disco con cache de 5 min. Soporta modo local (fs.statfs/PowerShell/df) y FTP (multiples estrategias).

2. **Estrategias FTP probadas (en orden)**:
   - Comandos FTP nativos: AVBL, SITE DF, STAT → no soportados por Synology
   - IP local via PASV → devolvio IP publica (37.14.56.55), no la local
   - Auto-descubrimiento NAS escaneando subnets 192.168.0.x y 192.168.1.x en puertos 5000/5001 → NAS no encontrado (DSM no accesible)
   - Synology DSM API (SYNO.Storage.CGI.Storage, SYNO.FileStation.List) → puertos cerrados en router Livebox 6
   - **Solucion final**: Listado recursivo FTP (`client.list()`) hasta 3 niveles de profundidad → 858 archivos, 2.44 TB

3. **Endpoint `POST /api/storage/nas-ip`**: Permite guardar la IP local del NAS manualmente para futuras consultas DSM.

4. **Frontend SettingsModal**: Nueva seccion "Almacenamiento NAS" con barra de progreso visual, tarjetas de datos, campo para IP del NAS.

5. **Configuracion de capacidad total**: Se guardo `nasTotalSize: 4000000000000` (4 TB) en storage-settings.json para calcular porcentaje y espacio libre.

### Codigo Relevante

**Listado recursivo FTP (routes/storage.js)**:
```javascript
async function getFTPUsedSpace(ftpConfig, ftpPath) {
    return await withFTPClient(ftpConfig, async (client) => {
        let totalSize = 0;
        let fileCount = 0;
        async function listRecursive(path, depth = 0) {
            if (depth > 2) return;
            const entries = await client.list(path);
            for (const entry of entries) {
                if (entry.name === '.' || entry.name === '..') continue;
                if (entry.type === 2) await listRecursive(`${path}/${entry.name}`, depth + 1);
                else if (entry.size) { totalSize += entry.size; fileCount++; }
            }
        }
        await listRecursive(ftpPath);
        return { used: totalSize, fileCount };
    }, { timeout: 120000 });
}
```

### Decisiones Tecnicas
- **Listado FTP como fallback universal**: Funciona con CUALQUIER servidor FTP, no depende de APIs propietarias
- **Cache de 5 minutos**: Evita saturar el FTP con consultas repetidas al abrir el modal
- **Capacidad total en config**: Como no se puede obtener por FTP, se guarda manualmente (4 TB)
- **Auto-descubrimiento multi-subnet**: Escanea tanto la subnet del servidor como subnets comunes de routers domesticos
- **3 niveles de profundidad FTP**: Suficiente para peliculas + series/temporada/episodio
- **Invalidacion de cache al cambiar modo**: Al cambiar FTP↔Local, se resetea el cache

### Problemas Encontrados y Soluciones

- **Problema**: Endpoint 404 tras implementacion
  **Solucion**: El servidor necesitaba reiniciarse (node server.js, no hot-reload)

- **Problema**: FTP no soporta AVBL, SITE DF, STAT
  **Solucion**: Implementar fallback con listado recursivo de archivos

- **Problema**: PASV devuelve IP publica (37.14.56.55) en vez de local
  **Solucion**: El NAS tiene configurado IP externa para PASV. Se implemento auto-descubrimiento por scan de red

- **Problema**: Auto-descubrimiento no encuentra NAS (servidor en 192.168.0.x, router en 192.168.1.x)
  **Solucion**: Se amplio escaneo a multiples subnets + campo manual de IP del NAS

- **Problema**: DSM puertos 5000/5001 no accesibles
  **Solucion**: Fallback definitivo a listado FTP + capacidad total manual (4 TB)
