#### 4. Toggle peticiones desde galeria de sagas
Click en pelicula no-catalogo crea una peticion (badge ambar "Pedida"); segundo click la cancela. Usa `toggleSagaRequest()` en `useRequests.js`.

```javascript
// useRequests.js - toggleSagaRequest
const toggleSagaRequest = async (movie) => {
  const existing = existingRequests.find(r =>
    Number(r.tmdbId) === Number(movie.tmdbId) && r.status !== 'server'
  );
  if (existing && existing.id) {
    // Ya pedida → eliminar
    await authFetch(`${API_BASE}/api/requests/${existing.id}`, { method: 'DELETE' });
    setExistingRequests(prev => prev.filter(r => r.id !== existing.id));
    setAllRequests(prev => prev.filter(r => r.id !== existing.id));
  } else {
    // No pedida → crear
    await authFetch(`${API_BASE}/api/requests`, { method: 'POST', ... });
    // Reload from server para obtener IDs correctos
  }
};
```

**Archivos**: `my-ui/src/hooks/useRequests.js`, `my-ui/src/App.js`

#### 5. Fix sincronizacion badge "Pedida" al borrar desde modal Peticiones
`deleteRequest` llamaba `loadAllRequests()` que sobreescribia `existingRequests`. Se reemplazo por actualizaciones directas de estado:

```javascript
// useRequests.js - deleteRequest fix
if (data.success) {
  setExistingRequests(prev => prev.filter(r => r.id !== id));
  setAllRequests(prev => prev.filter(r => r.id !== id));
}
```

**Archivos**: `my-ui/src/hooks/useRequests.js`

#### 6. Fix 401 en busqueda TMDB remota
Tres endpoints usaban `fetch` en vez de `authFetch`, causando 401 para usuarios remotos (JWT no incluido):

| Archivo | Linea | Endpoint |
|---------|-------|----------|
| `useRequests.js` | 84 | `/api/tmdb/search` |
| `useRequests.js` | 115 | `/api/tmdb/actor` |
| `useVideos.js` | 363 | `/api/tmdb/actor` |

**Fix**: Cambiar `fetch(...)` → `authFetch(...)` en los tres sitios.

#### 7. Deploy al NAS via calilu.mooo.com
WSL esta en subred 192.168.0.x, NAS en 192.168.1.45 — SSH directo no funciona. Se descubrio que SSH via `calilu.mooo.com` (dominio publico DDNS) si conecta. Deploy exitoso.

```bash
ssh isidro@calilu.mooo.com "rm -f ~/isiprime/my-ui/build/static/js/main.*.js ..."
scp -r my-ui/build/ isidro@calilu.mooo.com:~/isiprime/my-ui/
ssh isidro@calilu.mooo.com "cd ~/isiprime && pm2 restart isiprime"
```

### Decisiones Tecnicas
- **Paso a paso**: Tras un intento fallido de reorganizar todo el header de golpe ("ha sido un desastre"), se adopto enfoque incremental
- **`_notInCatalog` flag**: Se usa un flag en el objeto video para diferenciar rendering en la galeria, evitando componentes separados
- **Estado directo vs reload**: `deleteRequest` usa `setExistingRequests(prev => prev.filter(...))` en vez de recargar del servidor, para reactividad instantanea
- **Deploy via dominio publico**: WSL y NAS estan en subredes distintas; SSH via `calilu.mooo.com` es el workaround

### Problemas Encontrados y Soluciones

- **Problema**: Reorganizacion masiva del header rompio toda la pagina
  **Solucion**: `git checkout` para revertir, luego cambios incrementales

- **Problema**: Build viejo no se reemplazaba en NAS (archivo JS con hash diferente)
  **Solucion**: Borrar `main.*.js` y `main.*.css` antes de scp

- **Problema**: Badge "Pedida" no desaparecia al borrar desde modal Peticiones
  **Solucion**: Reemplazar `loadAllRequests()` por actualizaciones directas de estado React

- **Problema**: `toggleSagaRequest` usaba `data.requests` pero API devuelve `data.added`
  **Solucion**: Recargar lista completa del servidor tras crear peticion

- **Problema**: 401 en busqueda TMDB para usuarios remotos
  **Solucion**: 3 endpoints cambiados de `fetch` a `authFetch`

- **Problema**: SSH desde WSL no llega al NAS (subredes diferentes)
  **Solucion**: Usar `calilu.mooo.com` como host SSH
