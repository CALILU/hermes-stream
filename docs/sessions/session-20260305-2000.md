# Sesión 2026-03-05 20:00 — Streaming Mejorado + Conversión Masiva

## Resumen
Implementación de mejoras Netflix-inspired al streaming (ABR, buffer dinámico, probe on-demand), viewport adaptativo para `/tv` en PC, modal de gestión de usuarios rediseñado, y lanzamiento de conversión masiva en NAS (series + re-encode películas pesadas).

## Cambios Principales

### 1. Streaming — Dynamic Buffer (Phase 4)
- tv-player mide throughput con sliding window 10s
- Buffers ajustados según velocidad: fast (>5Mbps), normal (1-5Mbps), slow (<1Mbps)
- Archivo: `server.js` (inline tv-player HTML)

### 2. Streaming — ABR Adaptive Bitrate (Phase 2)
- Endpoint `/video-profiles/:filename` → perfiles de calidad según bitrate
- `/stream-fmp4/` acepta `?quality=medium|low` para re-encode on-the-fly
- `player.js` (TV app): handling `quality-change` message + `_reloadWithQuality`
- Archivos: `server.js`, `IsiPrime-WebOS-Native/js/player.js`

### 3. Streaming — Probe on-demand (Phase 3)
- `/stream-fmp4/` handler async, FFprobe si falta bitrate (~200ms)
- 837 películas re-probed en startup (tenían codec pero no bitrate)
- Archivos: `server.js`, `db/media-db.js`

### 4. Viewport `/tv` para PC
- Meta viewport `width=device-width` (antes fijo 1920)
- CSS transform scale con `transform-origin: 0 0`
- Archivo: `server.js` (ruta `/tv`)

### 5. Modal Gestión Usuarios
- Tarjetas expandibles con secciones: datos usuario + TVs asociadas + watching status
- Endpoints: PUT /:id genérico, POST/DELETE /:id/tvs
- Archivos: `UserManagementModal.js`, `useUsers.js`, `routes/auth.js`, `db/users-db.js`

### 6. Conversión Masiva NAS
- `scripts/convert-series-batch.js`: MKV/AVI→MP4 en `/mnt/peliculas/Series/` (31 archivos)
- `scripts/reencode-heavy-movies.js`: re-encode 27 películas >12000kbps → 8000k (~206GB ahorro)
- `scripts/run-all-conversions.sh`: cadena automática con emails de notificación
- Lanzado con `setsid nohup` en NAS (PIDs: series 15909, chain 18889)

## Notas Técnicas
- `nohup` via SSH no-interactiva no persiste. Solución: `setsid nohup cmd < /dev/null &`
- CRLF en scripts .sh creados en Windows: `sed -i 's/\r$//'` necesario
- ABR solo aplica a películas (series no tienen codec info en SQLite)
- Re-encode: safety checks (ratio >1.1 skip, <0.05 error, probe output)
